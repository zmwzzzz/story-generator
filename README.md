# AI故事生成器

一个基于AI的交互式故事生成工具，支持长篇和章节模式。

## 在线访问

部署后可以通过 GitHub Pages 访问。

## 功能特点

- 🎭 支持自定义剧情和世界观设定
- 📖 单篇长篇模式（2万字）
- 📚 多章节连续生成模式
- 💾 常用预设收藏功能
- 📱 移动端友好设计
- 🔒 API密钥本地存储，不上传服务器

## 使用方法

1. 打开网页
2. 点击"设置"按钮配置API密钥
3. 输入剧情设定
4. 选择生成模式
5. 点击"生成故事"

## 兼容的API

支持任何OpenAI兼容的API，包括：
- DeepSeek
- OpenAI
- 其他兼容服务

## 隐私说明

所有API密钥和设置仅存储在浏览器本地，不会上传到任何服务器。
